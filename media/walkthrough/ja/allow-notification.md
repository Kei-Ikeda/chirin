### 通知許可はここで取る

macOS の通知許可プロンプトは、**アプリが最初に通知を送ったとき**に一度だけ出ます。
chirin は `osascript`（別プロセス）経由で通知を送るため、macOS は chirin でも VS Code でもなく
スクリプト実行系のアプリに通知を帰属させます（Script Editor 系として表示されます。表記は
OS バージョンにより異なります）。

プロンプトを取り逃した場合や、あとから許可し直したいときは：

**システム設定 → 通知**を開き、テスト通知のあとに現れたエントリを選んで「通知を許可」を
オンにしてください。一度も通知を出していないとこの一覧に項目が現れないため、先にテスト通知を
送ってください。

テスト通知ではルールを選べます。実際のルールを選ぶと、そのテンプレートとサウンドで
発火するので、本番と同じ見た目・音を確認できます。
